# Demo HTML

För att testa webbsidan:

## Med VS Code
1. Klona repot från GitHub
1. Starta VS Code
1. Välj `File > Open Folder` och öppna mappen "06_web"
1. Klicka på knappen "Go Live" längst nere i högra hörnet på VS Code-fönstret. Webbsidan öppnas i din webbläsare.


## Med PyCharm
1. Starta PyCharm
1. Välj `File > Project from version control`
1. När du skriver i HTML-filen visas en inbyggd popup med ikoner för att visa webbsidan. Välj en.
